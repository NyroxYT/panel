# Nx Panel Logo Assets

Modern Nx Panel branding is available in `public/assets/logos/` and `public/favicons/`.

## SVG
- `public/assets/logos/nx-panel.svg` — horizontal Nx Panel wordmark (1024×256)
- `public/assets/logos/nx-panel-icon.svg` — square app icon (512×512)
- `public/assets/svgs/nxdactyl.svg` — Nx Panel icon replacement
- `public/assets/svgs/pterodactyl.svg` — Nx Panel branded replacement for legacy references
- `public/favicons/nx-panel.svg` and `favicon.svg` — favicon SVG

## Raster generation
The SVG masters are the source of truth. Raster variants can be generated at any required size with standard SVG tooling.

Brand gradient: `#A855F7 → #7C3AED → #22D3EE`.
